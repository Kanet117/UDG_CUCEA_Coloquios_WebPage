# Project Brief

## Project Name
Coloquio de Cuerpos Académicos (CCAs) — Página Web Institucional

## Client
Centro Universitario de Ciencias Económico Administrativas (CUCEA)
Universidad de Guadalajara (UdeG)

## Core Purpose
Migrar la página web oficial del Coloquio de Cuerpos Académicos (CCAs) desde un sitio Drupal a HTML/CSS/JS puro para independencia tecnológica y facilidad de despliegue.

## Key Requirements
1. Réplica visual exacta de las 5 páginas existentes en Drupal: Inicio, Comité, Conferencistas, Guías, Registro
2. Navbar y footer funcionales compartidos entre todas las páginas
3. Código limpio sin comentarios de IA, nivel MIT
4. Sin dependencias externas ni build tools — HTML estático puro
5. README.md con documentación del proyecto y lecciones aprendidas
6. .gitignore apropiado

## Scope
- 5 páginas de contenido + 1 página index con redirección
- Estilos CSS organizados: global.css (compartido) + un CSS por página
- JavaScript mínimo para redirecciones
- Sin backend, sin frameworks, sin librerías externas
